# Bellman 最优方程、压缩映射与最优策略

> 日期：2026-7-20

> 本节核心：从回报的递推关系出发，推导固定策略 Bellman 方程、Bellman 最优方程，并利用压缩映射证明价值函数的存在性、唯一性与迭代收敛性。

---

## 1. Markov Decision Process

一个折扣 Markov Decision Process（MDP）通常表示为：

```math
(\mathcal{S},\mathcal{A},P,R,\gamma)
```

其中：

- $\mathcal{S}$：状态集合；
- $\mathcal{A}(s)$：状态 $s$ 下可以选择的动作集合；
- $\pi(a\mid s)$：策略在状态 $s$ 下选择动作 $a$ 的概率；
- $P(s'\mid s,a)$：状态 $s$ 执行动作 $a$ 后转移到状态 $s'$ 的概率；
- $R_{t+1}$：环境在一次状态转移后产生的即时奖励；
- $\gamma\in[0,1)$：折扣因子。

智能体与环境之间的一次交互可以表示为：

```math
S_t=s
\;\xrightarrow{\pi(a\mid s)}\;
A_t=a
\;\xrightarrow{p(s',r\mid s,a)}\;
(S_{t+1}=s',R_{t+1}=r)
```

需要区分：

- $\pi(a\mid s)$ 由智能体的策略决定；
- $p(s',r\mid s,a)$ 由环境模型决定。

---

## 2. 环境模型中的奖励与状态转移

### 2.1 状态转移概率

定义：

```math
P(s'\mid s,a)
=
\Pr
\left(
S_{t+1}=s'
\mid
S_t=s,A_t=a
\right)
```

它表示：

> 在状态 $s$ 执行动作 $a$ 后，环境转移到状态 $s'$ 的概率。

对于任意状态动作对 $(s,a)$：

```math
P(s'\mid s,a)\ge 0
```

并且：

```math
\sum_{s'}P(s'\mid s,a)=1
```

---

### 2.2 条件期望奖励

如果奖励还依赖下一状态，可以定义：

```math
r(s,a,s')
=
\mathbb{E}
\left[
R_{t+1}
\mid
S_t=s,A_t=a,S_{t+1}=s'
\right]
```

状态 $s$ 下执行动作 $a$ 的期望即时奖励为：

```math
r(s,a)
=
\sum_{s'}
P(s'\mid s,a)r(s,a,s')
```

更一般地，也可以直接根据联合分布定义：

```math
r(s,a)
=
\sum_{s',r}
p(s',r\mid s,a)\,r
```

---

## 3. Return 的定义与递推形式

从时刻 $t$ 开始，无限时域折扣回报定义为：

```math
G_t
=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2R_{t+3}
+
\cdots
```

等价地：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

将第一项单独提取：

```math
\begin{aligned}
G_t
&=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2R_{t+3}
+
\cdots
\\
&=
R_{t+1}
+
\gamma
\left(
R_{t+2}
+
\gamma R_{t+3}
+
\gamma^2R_{t+4}
+
\cdots
\right)
\end{aligned}
```

括号中的部分正是 $G_{t+1}$，因此：

```math
\boxed{
G_t
=
R_{t+1}
+
\gamma G_{t+1}
}
```

这就是 Bellman 方程能够建立递归关系的基础。

---

## 4. State Value 与 Action Value

### 4.1 State Value

固定策略 $\pi$ 的状态价值函数定义为：

```math
\boxed{
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
}
```

它表示：

> 当前处于状态 $s$，之后始终按照策略 $\pi$ 行动时，未来折扣回报的期望。

---

### 4.2 Action Value

固定策略 $\pi$ 的动作价值函数定义为：

```math
\boxed{
q_\pi(s,a)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s,A_t=a
\right]
}
```

它表示：

> 当前处于状态 $s$，第一步固定执行动作 $a$，之后按照策略 $\pi$ 行动时，未来折扣回报的期望。

---

### 4.3 Action Value 的一步展开

根据：

```math
G_t
=
R_{t+1}
+
\gamma G_{t+1}
```

代入 action value 的定义：

```math
\begin{aligned}
q_\pi(s,a)
&=
\mathbb{E}_\pi
\left[
R_{t+1}
+
\gamma G_{t+1}
\mid
S_t=s,A_t=a
\right]
\end{aligned}
```

从下一状态开始的期望回报是 $v_\pi(S_{t+1})$，所以：

```math
q_\pi(s,a)
=
\mathbb{E}
\left[
R_{t+1}
+
\gamma v_\pi(S_{t+1})
\mid
S_t=s,A_t=a
\right]
```

离散状态下：

```math
\boxed{
q_\pi(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_\pi(s')
}
```

如果使用 $r(s,a,s')$，则：

```math
\boxed{
q_\pi(s,a)
=
\sum_{s'}
P(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma v_\pi(s')
\right]
}
```

---

### 4.4 State Value 与 Action Value 的关系

在状态 $s$ 下，策略按照概率 $\pi(a\mid s)$ 选择动作，所以：

```math
\boxed{
v_\pi(s)
=
\sum_a
\pi(a\mid s)q_\pi(s,a)
}
```

因此：

- state value 没有固定当前动作，需要对动作求期望；
- action value 固定了当前动作，不需要再对当前动作求期望。

---

## 5. 固定策略的 Bellman 期望方程

将 action value 代入 state value：

```math
v_\pi(s)
=
\sum_a
\pi(a\mid s)
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_\pi(s')
\right]
```

因此：

```math
\boxed{
v_\pi(s)
=
\sum_a
\pi(a\mid s)
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_\pi(s')
\right]
}
```

这就是固定策略 $\pi$ 的 Bellman expectation equation。

---

## 6. 固定策略 Bellman 方程的矩阵形式

假设有限状态空间为：

```math
\mathcal{S}
=
\{s_1,s_2,\ldots,s_n\}
```

定义价值向量：

```math
\mathbf{v}_\pi
=
\begin{bmatrix}
v_\pi(s_1)
\\
v_\pi(s_2)
\\
\vdots
\\
v_\pi(s_n)
\end{bmatrix}
```

定义策略 $\pi$ 下的期望奖励向量：

```math
\mathbf{r}_\pi
=
\begin{bmatrix}
r_\pi(s_1)
\\
r_\pi(s_2)
\\
\vdots
\\
r_\pi(s_n)
\end{bmatrix}
```

其中：

```math
r_\pi(s)
=
\sum_a
\pi(a\mid s)r(s,a)
```

定义策略 $\pi$ 下的状态转移矩阵：

```math
P_\pi(s,s')
=
\sum_a
\pi(a\mid s)P(s'\mid s,a)
```

写成矩阵：

```math
\mathbf{P}_\pi
=
\begin{bmatrix}
P_\pi(s_1,s_1)
&
P_\pi(s_1,s_2)
&
\cdots
&
P_\pi(s_1,s_n)
\\
P_\pi(s_2,s_1)
&
P_\pi(s_2,s_2)
&
\cdots
&
P_\pi(s_2,s_n)
\\
\vdots
&
\vdots
&
\ddots
&
\vdots
\\
P_\pi(s_n,s_1)
&
P_\pi(s_n,s_2)
&
\cdots
&
P_\pi(s_n,s_n)
\end{bmatrix}
```

固定策略 Bellman 方程的矩阵形式为：

```math
\boxed{
\mathbf{v}_\pi
=
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_\pi
}
```

为简化符号，后文也写成：

```math
v_\pi
=
r_\pi
+
\gamma P_\pi v_\pi
```

---

### 6.1 解析解

由：

```math
v_\pi
=
r_\pi
+
\gamma P_\pi v_\pi
```

移项得到：

```math
(I-\gamma P_\pi)v_\pi
=
r_\pi
```

因此：

```math
\boxed{
v_\pi
=
(I-\gamma P_\pi)^{-1}r_\pi
}
```

在状态数量较少时，可以直接求解该线性方程组。

---

## 7. 固定策略 Bellman 算子

定义固定策略 $\pi$ 的 Bellman 算子：

```math
\boxed{
f_\pi(v)
=
r_\pi
+
\gamma P_\pi v
}
```

固定策略的真实价值函数满足：

```math
\boxed{
v_\pi
=
f_\pi(v_\pi)
}
```

因此，$v_\pi$ 是 $f_\pi$ 的不动点。

---

## 8. 压缩映射定理

设 $(X,d)$ 是一个完备度量空间。

如果存在常数 $c\in[0,1)$，使得对任意 $x,y\in X$：

```math
d(f(x),f(y))
\le
c\,d(x,y)
```

那么 $f$ 是压缩映射。

压缩映射定理说明：

1. $f$ 存在不动点 $x^*$；
2. 不动点 $x^*$ 唯一；
3. 从任意初值 $x_0$ 开始迭代

```math
x_{k+1}
=
f(x_k)
```

都会收敛到 $x^*$；

4. 误差满足：

```math
d(x_k,x^*)
\le
c^k d(x_0,x^*)
```

这种收敛通常称为几何收敛。

---

## 9. 固定策略 Bellman 算子的压缩性

使用无穷范数：

```math
\lVert x\rVert_\infty
=
\max_s|x(s)|
```

对于任意两个价值向量 $v_1,v_2$：

```math
\begin{aligned}
\lVert f_\pi(v_1)-f_\pi(v_2)\rVert_\infty
&=
\left\lVert
r_\pi+\gamma P_\pi v_1
-
r_\pi-\gamma P_\pi v_2
\right\rVert_\infty
\\
&=
\gamma
\left\lVert
P_\pi(v_1-v_2)
\right\rVert_\infty
\end{aligned}
```

令：

```math
x=v_1-v_2
```

对于任意状态 $s$：

```math
(P_\pi x)(s)
=
\sum_{s'}
P_\pi(s,s')x(s')
```

所以：

```math
\begin{aligned}
|(P_\pi x)(s)|
&=
\left|
\sum_{s'}
P_\pi(s,s')x(s')
\right|
\\
&\le
\sum_{s'}
P_\pi(s,s')|x(s')|
\\
&\le
\sum_{s'}
P_\pi(s,s')\lVert x\rVert_\infty
\end{aligned}
```

由于 $P_\pi$ 每一行都是概率分布：

```math
\sum_{s'}
P_\pi(s,s')
=
1
```

因此：

```math
|(P_\pi x)(s)|
\le
\lVert x\rVert_\infty
```

对所有状态取最大值：

```math
\lVert P_\pi x\rVert_\infty
\le
\lVert x\rVert_\infty
```

最终得到：

```math
\boxed{
\lVert f_\pi(v_1)-f_\pi(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

因为：

```math
0\le\gamma<1
```

所以 $f_\pi$ 是 $\gamma$-压缩映射。

---

### 9.1 固定策略 Bellman 方程的结论

由压缩映射定理：

1. 固定策略 Bellman 方程存在解；
2. 解唯一；
3. 唯一解就是 $v_\pi$；
4. 从任意初值 $v_0$ 开始迭代都会收敛到 $v_\pi$。

迭代公式为：

```math
\boxed{
v_{k+1}
=
f_\pi(v_k)
=
r_\pi+\gamma P_\pi v_k
}
```

并且：

```math
\lim_{k\to\infty}v_k
=
v_\pi
```

误差满足：

```math
\boxed{
\lVert v_k-v_\pi\rVert_\infty
\le
\gamma^k
\lVert v_0-v_\pi\rVert_\infty
}
```

## 10. 从随机策略最大化到动作最大化

先固定一个任意价值函数 $v$，定义一步 action value：

```math
q_v(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v(s')
```

现在考虑：

```math
\max_\pi
\sum_a
\pi(a\mid s)q_v(s,a)
```

由于策略概率满足：

```math
\pi(a\mid s)\ge0
```

以及：

```math
\sum_a
\pi(a\mid s)
=
1
```

所以：

```math
\sum_a
\pi(a\mid s)q_v(s,a)
```

是所有 $q_v(s,a)$ 的加权平均。

令：

```math
M
=
\max_a q_v(s,a)
```

则对于每个动作 $a$：

```math
q_v(s,a)
\le
M
```

两边乘以 $\pi(a\mid s)$ 并求和：

```math
\begin{aligned}
\sum_a
\pi(a\mid s)q_v(s,a)
&\le
\sum_a
\pi(a\mid s)M
\\
&=
M
\sum_a
\pi(a\mid s)
\\
&=
M
\end{aligned}
```

因此：

```math
\sum_a
\pi(a\mid s)q_v(s,a)
\le
\max_a q_v(s,a)
```

该上界可以达到。

选择：

```math
a^*
\in
\operatorname*{arg\,max}_a
q_v(s,a)
```

并令：

```math
\pi(a\mid s)
=
\begin{cases}
1, & a=a^*
\\
0, & a\ne a^*
\end{cases}
```

就可以得到：

```math
\boxed{
\max_\pi
\sum_a
\pi(a\mid s)q_v(s,a)
=
\max_a q_v(s,a)
}
```

如果多个动作并列最大，那么任意只在这些最大动作之间分配概率的策略都能达到最大值。

## 11. Bellman 最优方程

定义 Bellman 最优算子 $f$：

```math
\boxed{
(f(v))(s)
=
\max_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v(s')
\right]
}
```

Bellman 最优方程为：

```math
\boxed{
v^*
=
f(v^*)
}
```

逐状态展开：

```math
\boxed{
v^*(s)
=
\max_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
\right]
}
```

---

## 12. Bellman 最优方程的矩阵形式

对于任意策略 $\pi$：

```math
f_\pi(v)
=
r_\pi
+
\gamma P_\pi v
```

Bellman 最优算子可以写成：

```math
\boxed{
f(v)
=
\max_\pi
\left(
r_\pi
+
\gamma P_\pi v
\right)
}
```

这里的 $\max$ 是逐分量最大值。

具体来说：

```math
(f(v))(s)
=
\max_\pi
\left[
r_\pi
+
\gamma P_\pi v
\right]_s
```

矩阵中的第 $s$ 行对应状态 $s$。

因此，每个状态可以独立选择使当前行结果最大的动作。

例如：

- 状态 $s_1$ 选择动作 $a_2$；
- 状态 $s_2$ 选择动作 $a_1$；
- 状态 $s_3$ 选择动作 $a_3$。

这些逐状态动作组合起来构成一个完整策略。

不能将最大值拆开写成：

```math
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)
=
\max_\pi r_\pi
+
\gamma
\left(
\max_\pi P_\pi
\right)v
```

因为最大化必须作用在完整的一步价值上：

```math
r(s,a)
+
\gamma
P_a(s,:)v
```

---

## 13. Bellman 最优算子的压缩性

需要证明：

```math
\boxed{
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

---

### 13.1 最大值不等式

对于任意两组实数 $\{x_a\}$ 和 $\{y_a\}$：

```math
\boxed{
\left|
\max_a x_a
-
\max_a y_a
\right|
\le
\max_a
|x_a-y_a|
}
```

证明如下。

选择：

```math
a_1
\in
\operatorname*{arg\,max}_a x_a
```

则：

```math
\max_a x_a
=
x_{a_1}
```

同时：

```math
\max_a y_a
\ge
y_{a_1}
```

因此：

```math
\begin{aligned}
\max_a x_a
-
\max_a y_a
&\le
x_{a_1}-y_{a_1}
\\
&\le
\max_a|x_a-y_a|
\end{aligned}
```

交换 $x$ 和 $y$，同样有：

```math
\max_a y_a
-
\max_a x_a
\le
\max_a|x_a-y_a|
```

所以：

```math
\left|
\max_a x_a
-
\max_a y_a
\right|
\le
\max_a|x_a-y_a|
```

---

### 13.2 应用于 Bellman 最优算子

固定状态 $s$，定义：

```math
x_a
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_1(s')
```

以及：

```math
y_a
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_2(s')
```

那么：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&=
\left|
\max_a x_a
-
\max_a y_a
\right|
\\
&\le
\max_a|x_a-y_a|
\end{aligned}
```

奖励项相消：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&\le
\gamma
\max_a
\left|
\sum_{s'}
P(s'\mid s,a)
\left(
v_1(s')-v_2(s')
\right)
\right|
\\
&\le
\gamma
\max_a
\sum_{s'}
P(s'\mid s,a)
\left|
v_1(s')-v_2(s')
\right|
\end{aligned}
```

根据无穷范数定义：

```math
|v_1(s')-v_2(s')|
\le
\lVert v_1-v_2\rVert_\infty
```

所以：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&\le
\gamma
\max_a
\sum_{s'}
P(s'\mid s,a)
\lVert v_1-v_2\rVert_\infty
\\
&=
\gamma
\lVert v_1-v_2\rVert_\infty
\end{aligned}
```

最后对所有状态取最大值：

```math
\boxed{
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

由于 $\gamma<1$，所以 Bellman 最优算子 $f$ 是压缩映射。

## 14. Bellman 最优方程的存在性、唯一性与迭代算法

由压缩映射定理，Bellman 最优方程：

```math
v=f(v)
```

具有以下性质。

### 14.1 存在性

存在一个向量 $v^*$ 满足：

```math
v^*
=
f(v^*)
```

---

### 14.2 唯一性

满足 Bellman 最优方程的不动点只有一个。

因此不存在两个不同的向量同时满足：

```math
v
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)
```

---

### 14.3 Value Iteration

从任意有限初始向量 $v_0$ 开始：

```math
\boxed{
v_{k+1}
=
f(v_k)
}
```

逐状态形式为：

```math
v_{k+1}(s)
=
\max_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_k(s')
\right]
```

矩阵形式为：

```math
v_{k+1}
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v_k
\right)
```

则：

```math
\boxed{
\lim_{k\to\infty}v_k
=
v^*
}
```

---

### 14.4 收敛速度

误差满足：

```math
\boxed{
\lVert v_k-v^*\rVert_\infty
\le
\gamma^k
\lVert v_0-v^*\rVert_\infty
}
```

因此：

- $\gamma$ 较小时，理论收敛通常更快；
- $\gamma$ 越接近 $1$，理论收敛通常越慢。

---

### 14.5 Bellman Residual

对于任意价值向量 $v$：

```math
\begin{aligned}
\lVert v-v^*\rVert_\infty
&=
\lVert v-f(v)+f(v)-f(v^*)\rVert_\infty
\\
&\le
\lVert v-f(v)\rVert_\infty
+
\lVert f(v)-f(v^*)\rVert_\infty
\\
&\le
\lVert v-f(v)\rVert_\infty
+
\gamma
\lVert v-v^*\rVert_\infty
\end{aligned}
```

移项得到：

```math
\boxed{
\lVert v-v^*\rVert_\infty
\le
\frac{1}{1-\gamma}
\lVert f(v)-v\rVert_\infty
}
```

这说明，当 Bellman residual 足够小时，当前价值估计就接近 $v^*$。

---

## 15. 从 $v^*$ 构造策略 $\pi^*$

在每个状态选择使 Bellman 最优方程右侧达到最大值的动作：

```math
\boxed{
\pi^*(s)
\in
\operatorname*{arg\,max}_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
\right]
}
```

因为 $\pi^*$ 在每个状态都取得最大值：

```math
v^*
=
r_{\pi^*}
+
\gamma P_{\pi^*}v^*
```

也就是：

```math
v^*
=
f_{\pi^*}(v^*)
```

这说明 $v^*$ 是固定策略算子 $f_{\pi^*}$ 的一个不动点。

另一方面，策略 $\pi^*$ 的价值函数满足：

```math
v_{\pi^*}
=
f_{\pi^*}(v_{\pi^*})
```

由于 $f_{\pi^*}$ 是压缩映射，它的不动点唯一。

因此：

```math
\boxed{
v^*
=
v_{\pi^*}
}
```

这一步说明：

> Bellman 最优方程的数学解 $v^*$，确实可以由策略 $\pi^*$ 实际实现。

---

## 16. 证明 $\pi^*$ 是最优策略

只证明：

```math
v^*
=
v_{\pi^*}
```

还不足以说明 $\pi^*$ 比其他所有策略都好。

还需要证明：

```math
\boxed{
v^*
\ge
v_\pi,
\qquad
\forall\pi
}
```

这里的不等号是逐状态意义：

```math
v^*(s)
\ge
v_\pi(s),
\qquad
\forall s,\forall\pi
```

---

### 16.1 固定任意策略 $\pi$

为了避免最大化变量和固定策略 $\pi$ 混淆，将最大化变量记为 $\bar{\pi}$。

由 Bellman 最优方程：

```math
v^*
=
\max_{\bar{\pi}}
\left(
r_{\bar{\pi}}
+
\gamma P_{\bar{\pi}}v^*
\right)
```

最大值一定不小于其中任意一个候选策略 $\pi$：

```math
v^*
\ge
r_\pi+\gamma P_\pi v^*
```

即：

```math
\boxed{
v^*
\ge
f_\pi(v^*)
}
```

---

### 16.2 固定策略 Bellman 算子的单调性

如果：

```math
x\ge y
```

那么：

```math
\begin{aligned}
f_\pi(x)-f_\pi(y)
&=
r_\pi+\gamma P_\pi x
-
r_\pi-\gamma P_\pi y
\\
&=
\gamma P_\pi(x-y)
\end{aligned}
```

因为：

```math
x-y\ge0
```

并且 $P_\pi$ 的所有元素非负，所以：

```math
P_\pi(x-y)\ge0
```

因此：

```math
\boxed{
x\ge y
\quad\Longrightarrow\quad
f_\pi(x)\ge f_\pi(y)
}
```

这就是固定策略 Bellman 算子的单调性。

---

### 16.3 反复应用 $f_\pi$

已经知道：

```math
v^*
\ge
f_\pi(v^*)
```

根据单调性，对两边同时作用 $f_\pi$：

```math
f_\pi(v^*)
\ge
f_\pi^2(v^*)
```

继续迭代：

```math
v^*
\ge
f_\pi(v^*)
\ge
f_\pi^2(v^*)
\ge
f_\pi^3(v^*)
\ge
\cdots
```

由于 $f_\pi$ 是压缩映射：

```math
\lim_{k\to\infty}
f_\pi^k(v^*)
=
v_\pi
```

对不等式取极限：

```math
\boxed{
v^*
\ge
v_\pi
}
```

由于 $\pi$ 是任意策略：

```math
\boxed{
v^*
\ge
v_\pi,
\qquad
\forall\pi
}
```

再结合：

```math
v^*
=
v_{\pi^*}
```

得到：

```math
\boxed{
v_{\pi^*}
=
v^*
\ge
v_\pi,
\qquad
\forall\pi
}
```

因此：

```math
\boxed{
\pi^*
\text{ 是最优策略}
}
```

同时：

```math
\boxed{
v^*(s)
=
\max_\pi v_\pi(s)
}
```

需要注意：

- 最优价值函数 $v^*$ 唯一；
- 最优策略 $\pi^*$ 不一定唯一；
- 如果多个动作并列最大，就可能存在多个最优策略。

---

## 17. Optimal Action Value

最优 action value 定义为：

```math
\boxed{
q^*(s,a)
=
\max_\pi q_\pi(s,a)
}
```

根据一步展开：

```math
\boxed{
q^*(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
}
```

最优 state value 与最优 action value 的关系为：

```math
\boxed{
v^*(s)
=
\max_a q^*(s,a)
}
```

最优动作可以通过以下方式得到：

```math
\boxed{
\pi^*(s)
\in
\operatorname*{arg\,max}_a
q^*(s,a)
}
```

Bellman 最优方程也可以写成 action value 形式：

```math
\boxed{
q^*(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)
\max_{a'}
q^*(s',a')
}
```

---

## 18. Reward 的仿射变换

为了避免与动作符号 $a$ 混淆，使用 $\alpha$ 表示奖励缩放系数。

假设每一步奖励统一变换为：

```math
R'_{t+1}
=
\alpha R_{t+1}
+
b
```

为了保证最优策略不变，需要：

```math
\boxed{
\alpha>0
}
```

---

### 18.1 Return 的变化

变换后的 Return 为：

```math
\begin{aligned}
G'_t
&=
\sum_{k=0}^{\infty}
\gamma^k
\left(
\alpha R_{t+k+1}+b
\right)
\\
&=
\alpha
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
+
b
\sum_{k=0}^{\infty}
\gamma^k
\\
&=
\alpha G_t
+
\frac{b}{1-\gamma}
\end{aligned}
```

因此：

```math
\boxed{
G'_t
=
\alpha G_t
+
\frac{b}{1-\gamma}
}
```

---

### 18.2 固定策略 State Value 的变化

对任意固定策略 $\pi$：

```math
\begin{aligned}
v'_\pi(s)
&=
\mathbb{E}_\pi
\left[
G'_t
\mid
S_t=s
\right]
\\
&=
\mathbb{E}_\pi
\left[
\alpha G_t
+
\frac{b}{1-\gamma}
\mid
S_t=s
\right]
\\
&=
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
\end{aligned}
```

所以：

```math
\boxed{
v'_\pi(s)
=
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
}
```

向量形式为：

```math
\boxed{
v'_\pi
=
\alpha v_\pi
+
\frac{b}{1-\gamma}\mathbf{1}
}
```

其中：

```math
\mathbf{1}
=
\begin{bmatrix}
1
\\
1
\\
\vdots
\\
1
\end{bmatrix}
```

---

### 18.3 固定策略 Action Value 的变化

同理：

```math
\begin{aligned}
q'_\pi(s,a)
&=
\mathbb{E}_\pi
\left[
G'_t
\mid
S_t=s,A_t=a
\right]
\\
&=
\alpha q_\pi(s,a)
+
\frac{b}{1-\gamma}
\end{aligned}
```

因此：

```math
\boxed{
q'_\pi(s,a)
=
\alpha q_\pi(s,a)
+
\frac{b}{1-\gamma}
}
```

---

### 18.4 最优 State Value 的变化

变换后的最优价值函数为：

```math
v'^*(s)
=
\max_\pi v'_\pi(s)
```

代入仿射关系：

```math
v'^*(s)
=
\max_\pi
\left[
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
\right]
```

因为 $\alpha>0$：

```math
\begin{aligned}
v'^*(s)
&=
\alpha
\max_\pi v_\pi(s)
+
\frac{b}{1-\gamma}
\\
&=
\alpha v^*(s)
+
\frac{b}{1-\gamma}
\end{aligned}
```

因此：

```math
\boxed{
v'^*
=
\alpha v^*
+
\frac{b}{1-\gamma}\mathbf{1}
}
```

---

### 18.5 最优 Action Value 的变化

同理：

```math
\boxed{
q'^*(s,a)
=
\alpha q^*(s,a)
+
\frac{b}{1-\gamma}
}
```

---

### 18.6 最优策略为什么不变

变换后的最优动作集合为：

```math
\operatorname*{arg\,max}_a
q'^*(s,a)
```

代入：

```math
\operatorname*{arg\,max}_a
\left[
\alpha q^*(s,a)
+
\frac{b}{1-\gamma}
\right]
```

其中：

- $\frac{b}{1-\gamma}$ 对所有动作相同，不改变动作排序；
- $\alpha>0$，正数缩放不改变大小关系。

因此：

```math
\boxed{
\operatorname*{arg\,max}_a
q'^*(s,a)
=
\operatorname*{arg\,max}_a
q^*(s,a)
}
```

所以最优策略集合不变。

如果 $\alpha<0$，大小关系会反转，此时不能保证最优策略不变。

---

### 18.7 适用条件

公式：

```math
\frac{b}{1-\gamma}
```

适用于无限时域折扣任务，或者终止状态被视为吸收状态并继续按照相同规则处理奖励的情况。

对于固定长度为 $H$ 的有限时域任务：

```math
\sum_{k=0}^{H-1}
\gamma^k b
=
b
\frac{1-\gamma^H}{1-\gamma}
```

如果不同策略会造成不同的 episode 长度，并且终止后不再产生奖励，那么每一步统一增加常数 $b$ 可能改变对 episode 长度的偏好。

在这种情况下，最优策略不一定保持不变。

---

## 19. Reward 与折扣因子 $\gamma$ 的真正含义

### 19.1 Reward 决定优化目标

Reward 定义智能体应该偏好什么结果。

例如：

- 到达目标获得正奖励；
- 进入危险区域获得负奖励；
- 消耗资源产生负奖励；
- 收集物品获得正奖励；
- 每移动一步产生一定成本。

Reward 并不是直接给 state value 赋值。

Reward 首先参与定义 Return：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

然后 state value 是 Return 的条件期望：

```math
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
```

所以 Reward 通过 Return 间接影响 state value 和 action value。

---

### 19.2 $\gamma$ 决定未来奖励的重要程度

第 $k$ 步后的奖励在 Return 中的权重为：

```math
\gamma^k
```

当 $\gamma$ 较小时：

- 更重视近期奖励；
- 较远奖励迅速贬值；
- 有效规划范围较短；
- Bellman 迭代通常收敛更快。

当 $\gamma$ 接近 $1$ 时：

- 更重视长期奖励；
- 较远奖励仍然有较大影响；
- 有效规划范围更长；
- Bellman 迭代理论上更慢。

一个常用的粗略有效时间尺度为：

```math
\frac{1}{1-\gamma}
```

例如：

```math
\gamma=0.9
\quad\Longrightarrow\quad
\frac{1}{1-\gamma}=10
```

```math
\gamma=0.99
\quad\Longrightarrow\quad
\frac{1}{1-\gamma}=100
```

这不是严格的截止步数，而是理解长期影响范围的一种近似方式。

---

### 19.3 $\gamma$ 的数学作用

$\gamma<1$ 还使 Bellman 算子满足：

```math
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
```

因此 Bellman 算子成为压缩映射，从而保证：

- 不动点存在；
- 不动点唯一；
- 价值迭代收敛。

---

## 20. 九宫格中为什么零步进奖励也可能产生短路径

假设：

- 普通白色格子奖励为 $0$；
- 到达目标获得奖励 $R_g>0$；
- 途中没有其他奖励；
- 从当前状态经过 $d$ 步到达目标；
- $0<\gamma<1$。

如果目标奖励在第 $d$ 步获得，则当前 Return 为：

```math
G_t
=
\gamma^{d-1}R_g
```

假设两条路径长度分别为 $d_1$ 和 $d_2$，并且：

```math
d_1<d_2
```

由于：

```math
0<\gamma<1
```

所以：

```math
\gamma^{d_1-1}
>
\gamma^{d_2-1}
```

因此：

```math
\gamma^{d_1-1}R_g
>
\gamma^{d_2-1}R_g
```

较短路径具有更大的价值。

此时并不是白色格子的零奖励在惩罚绕路，而是 $\gamma<1$ 使较晚得到的目标奖励被折扣。

---

### 20.1 当 $\gamma=1$ 时

如果：

- 普通格子奖励为 $0$；
- 所有路径最终到达同一个奖励为 $R_g$ 的目标；
- 不考虑失败概率和其他奖励；
- $\gamma=1$。

那么无论路径长度是多少：

```math
G_t
=
R_g
```

长路径与短路径具有相同 Return。

此时目标函数本身并不严格偏好最短路径。

算法最终恰好选择短路径，可能来自：

- 初始化方式；
- 探索过程；
- 动作平局处理方式；
- 更新顺序；
- 环境实现细节。

---

### 20.2 每步负奖励的作用

另一种鼓励短路径的方法是令每一步产生负奖励。

例如：

```math
R_{t+1}
=
-c,
\qquad
c>0
```

假设经过 $d$ 步到达奖励为 $R_g$ 的目标，并且 $\gamma=1$，则：

```math
G_t
=
R_g-c(d-1)
```

路径越长，累计成本越大，所以短路径的价值越高。

---

### 20.3 每步负奖励与折扣的区别

两种方法都可能鼓励较短路径，但含义不同：

- 每步负奖励：移动或延迟本身具有实际成本；
- $\gamma<1$：较晚获得的奖励相对于近期奖励发生贬值。

两者并不完全等价。

如果环境存在以下因素，最优策略不一定是几何距离最短的路径：

- 路径中存在额外奖励；
- 某些区域具有危险；
- 状态转移是随机的；
- 存在多个奖励不同的终点；
- 不同路径具有不同成功概率；
- 某些动作消耗更多资源。

智能体真正最大化的是：

```math
\mathbb{E}_\pi
\left[
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
\right]
```

而不是单纯最小化路径长度。

---

## 21. Reward、$\gamma$、环境与策略之间的关系

各部分的作用可以概括为：

- $R$：定义什么结果值得追求；
- $\gamma$：定义未来奖励相对于近期奖励的重要程度；
- $P$：定义环境在动作之后如何变化；
- $\pi$：定义智能体如何选择动作；
- $v_\pi$：表示从某个状态出发的期望折扣回报；
- $q_\pi$：表示从某个状态执行某个动作后的期望折扣回报。

Reward 和 $\gamma$ 并不是直接设置 state value。

它们首先共同定义 Return：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

然后 state value 和 action value 是 Return 的条件期望。

## 23. 整体逻辑总结

固定策略 Bellman 算子满足：

```math
\lVert f_\pi(v_1)-f_\pi(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
```

所以固定策略 Bellman 方程存在唯一解 $v_\pi$。

Bellman 最优算子满足：

```math
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
```

所以 Bellman 最优方程存在唯一解 $v^*$。

从任意初始值开始进行 Value Iteration：

```math
v_{k+1}
=
f(v_k)
```

都会收敛到：

```math
v^*
```

根据 $v^*$ 构造贪心策略：

```math
\pi^*(s)
\in
\operatorname*{arg\,max}_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
\right]
```

因为：

```math
v^*
=
f_{\pi^*}(v^*)
```

而 $f_{\pi^*}$ 的不动点唯一，所以：

```math
v^*
=
v_{\pi^*}
```

对于任意策略 $\pi$：

```math
v^*
\ge
v_\pi
```

最终得到：

```math
\boxed{
v_{\pi^*}
=
v^*
\ge
v_\pi,
\qquad
\forall\pi
}
```

因此：

```math
\boxed{
\pi^*
\text{ 是最优策略}
}
```

整套逻辑可以概括为：

1. 从 Return 的递推关系得到 Bellman 方程；
2. 固定策略 Bellman 算子是压缩映射；
3. 固定策略价值函数存在且唯一；
4. Bellman 最优算子也是压缩映射；
5. Bellman 最优方程存在唯一解 $v^*$；
6. Value Iteration 从任意初值收敛到 $v^*$；
7. 根据 $v^*$ 构造贪心策略 $\pi^*$；
8. 证明 $v_{\pi^*}=v^*$；
9. 证明 $v^*\ge v_\pi$ 对所有策略成立；
10. 因此 $\pi^*$ 是最优策略，$v^*$ 是最优价值函数。
