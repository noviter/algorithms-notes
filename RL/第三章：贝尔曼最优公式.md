# Bellman 最优方程、压缩映射与最优策略
> 日期：2026-7-20
## 1. Markov Decision Process

一个折扣 Markov Decision Process（MDP）通常写成：

```math
(\mathcal{S},\mathcal{A},P,R,\gamma)
```

其中：

- $\mathcal{S}$：状态集合；
- $\mathcal{A}(s)$：状态 $s$ 下可以选择的动作集合；
- $\pi(a\mid s)$：策略在状态 $s$ 下选择动作 $a$ 的概率；
- $P(s'\mid s,a)$：在状态 $s$ 执行动作 $a$ 后，转移到状态 $s'$ 的概率；
- $R_{t+1}$：环境在一次状态转移后给出的即时奖励；
- $\gamma\in[0,1)$：折扣因子。

智能体和环境之间的交互过程可以表示为：

```math
S_t=s
\xrightarrow{\pi(a\mid s)}
A_t=a
\xrightarrow{p(s',r\mid s,a)}
(S_{t+1}=s',R_{t+1}=r)
```

需要区分两类概率：

- $\pi(a\mid s)$ 由智能体的策略决定；
- $p(s',r\mid s,a)$ 由环境模型决定。

如果把奖励分布压缩成期望奖励，可以定义：

```math
r(s,a)
=
\mathbb{E}
\left[
R_{t+1}
\mid
S_t=s,\ A_t=a
\right]
```

更完整地，也可以写成：

```math
r(s,a)
=
\sum_{s',r}
p(s',r\mid s,a)\,r
```

# 2. Return、state value 与 action value

## 2.1 Return

无限时域折扣回报定义为：

```math
G_t
=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2R_{t+3}
+
\cdots
```

等价地：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

Return 可以进行一步展开：

```math
G_t
=
R_{t+1}
+
\gamma G_{t+1}
```

---

## 2.2 State value

固定策略 $\pi$ 的状态价值函数定义为：

```math
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
```

它表示：

> 当前处于状态 $s$，之后始终按照策略 $\pi$ 行动时，未来折扣回报的期望。

---

## 2.3 Action value

固定策略 $\pi$ 的动作价值函数定义为：

```math
q_\pi(s,a)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s,\ A_t=a
\right]
```

它表示：

> 当前处于状态 $s$，第一步执行动作 $a$，之后按照策略 $\pi$ 行动时，未来折扣回报的期望。

利用 Return 的一步展开：

```math
G_t
=
R_{t+1}
+
\gamma G_{t+1}
```

可以得到：

```math
q_\pi(s,a)
=
\mathbb{E}
\left[
R_{t+1}
+
\gamma v_\pi(S_{t+1})
\mid
S_t=s,\ A_t=a
\right]
```

在离散状态空间中：

```math
q_\pi(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_\pi(s')
```

---

# 3. 固定策略的 Bellman 方程

## 3.1 标量形式

在状态 $s$ 下，策略 $\pi$ 可能按照不同概率选择不同动作，因此：

```math
v_\pi(s)
=
\sum_a
\pi(a\mid s)q_\pi(s,a)
```

代入 action value 的定义：

```math
v_\pi(s)
=
\sum_a
\pi(a\mid s)
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_\pi(s')
\right]
```

这就是固定策略 $\pi$ 的 Bellman expectation equation。

---

## 3.2 矩阵形式

假设状态数量为 $|\mathcal{S}|$。

定义价值向量：

```math
v_\pi
=
\begin{bmatrix}
v_\pi(s_1)\\
v_\pi(s_2)\\
\vdots\\
v_\pi(s_{|\mathcal{S}|})
\end{bmatrix}
```

定义策略 $\pi$ 下的期望奖励向量：

```math
r_\pi
=
\begin{bmatrix}
r_\pi(s_1)\\
r_\pi(s_2)\\
\vdots\\
r_\pi(s_{|\mathcal{S}|})
\end{bmatrix}
```

定义策略 $\pi$ 下的状态转移矩阵：

```math
P_\pi(s,s')
=
\sum_a
\pi(a\mid s)P(s'\mid s,a)
```

于是固定策略 Bellman 方程可以写为：

```math
v_\pi
=
r_\pi
+
\gamma P_\pi v_\pi
```

定义固定策略 Bellman 算子：

```math
f_\pi(v)
=
r_\pi
+
\gamma P_\pi v
```

那么：

```math
v_\pi
=
f_\pi(v_\pi)
```

因此，$v_\pi$ 是算子 $f_\pi$ 的不动点。

---

## 3.3 直接求解

由：

```math
v_\pi
=
r_\pi
+
\gamma P_\pi v_\pi
```

移项得到：

```math
(I-\gamma P_\pi)v_\pi
=
r_\pi
```

因此：

```math
v_\pi
=
(I-\gamma P_\pi)^{-1}r_\pi
```

在状态数较小时可以直接求解该线性方程；状态数较大时通常采用迭代方法。

---

# 4. 固定策略 Bellman 算子的压缩性

使用无穷范数：

```math
\lVert x\rVert_\infty
=
\max_s|x(s)|
```

对于任意两个价值向量 $v_1,v_2$：

```math
\begin{aligned}
\lVert f_\pi(v_1)-f_\pi(v_2)\rVert_\infty
&=
\left\lVert
r_\pi+\gamma P_\pi v_1
-
r_\pi-\gamma P_\pi v_2
\right\rVert_\infty\\
&=
\gamma
\left\lVert
P_\pi(v_1-v_2)
\right\rVert_\infty
\end{aligned}
```

令：

```math
x=v_1-v_2
```

对于任意状态 $s$：

```math
(P_\pi x)(s)
=
\sum_{s'}
P_\pi(s,s')x(s')
```

所以：

```math
\begin{aligned}
|(P_\pi x)(s)|
&=
\left|
\sum_{s'}
P_\pi(s,s')x(s')
\right|\\
&\le
\sum_{s'}
P_\pi(s,s')|x(s')|\\
&\le
\sum_{s'}
P_\pi(s,s')\lVert x\rVert_\infty
\end{aligned}
```

由于转移矩阵的每一行都是概率分布：

```math
\sum_{s'}P_\pi(s,s')=1
```

因此：

```math
|(P_\pi x)(s)|
\le
\lVert x\rVert_\infty
```

对所有状态取最大值：

```math
\lVert P_\pi x\rVert_\infty
\le
\lVert x\rVert_\infty
```

所以：

```math
\boxed{
\lVert f_\pi(v_1)-f_\pi(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

因为：

```math
0\le\gamma<1
```

所以 $f_\pi$ 是一个 $\gamma$-压缩映射。

由压缩映射定理：

1. $f_\pi$ 存在不动点；
2. 该不动点唯一；
3. 唯一不动点就是 $v_\pi$；
4. 从任意初始值 $v_0$ 开始迭代都会收敛到 $v_\pi$。

迭代形式为：

```math
v_{k+1}
=
f_\pi(v_k)
=
r_\pi+\gamma P_\pi v_k
```

并且：

```math
v_k
\longrightarrow
v_\pi
```

---

# 5. 从随机策略最大化到动作最大化

先固定一个价值函数 $v$，定义：

```math
q_v(s,a)
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v(s')
```

现在考虑：

```math
\max_\pi
\sum_a
\pi(a\mid s)q_v(s,a)
```

策略概率满足：

```math
\pi(a\mid s)\ge0
```

以及：

```math
\sum_a\pi(a\mid s)=1
```

因此：

```math
\sum_a
\pi(a\mid s)q_v(s,a)
```

是不同 $q_v(s,a)$ 的加权平均。

令：

```math
M
=
\max_a q_v(s,a)
```

对任意动作 $a$：

```math
q_v(s,a)\le M
```

两边乘以非负数 $\pi(a\mid s)$ 并求和：

```math
\begin{aligned}
\sum_a
\pi(a\mid s)q_v(s,a)
&\le
\sum_a
\pi(a\mid s)M\\
&=
M
\sum_a
\pi(a\mid s)\\
&=
M
\end{aligned}
```

因此：

```math
\sum_a
\pi(a\mid s)q_v(s,a)
\le
\max_a q_v(s,a)
```

该上界可以达到。只需要选择：

```math
a^*
\in
\operatorname*{arg\,max}_a
q_v(s,a)
```

并令：

```math
\pi(a\mid s)
=
\begin{cases}
1, & a=a^*\\
0, & a\ne a^*
\end{cases}
```

所以：

```math
\boxed{
\max_\pi
\sum_a
\pi(a\mid s)q_v(s,a)
=
\max_a q_v(s,a)
}
```

这里不是简单地让最大 action value 对应动作的概率“更大”，而是在最大动作唯一时，直接令其概率为 $1$。

如果多个动作并列最大，那么任意只在这些最优动作之间分配概率的策略都能达到最大值。

---

# 6. Bellman 最优方程

## 6.1 标量形式

定义 Bellman 最优算子 $f$：

```math
(f(v))(s)
=
\max_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v(s')
\right]
```

Bellman 最优方程为：

```math
v^*
=
f(v^*)
```

展开为：

```math
\boxed{
v^*(s)
=
\max_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
\right]
}
```

---

## 6.2 矩阵形式

对于任意策略 $\pi$：

```math
f_\pi(v)
=
r_\pi+\gamma P_\pi v
```

Bellman 最优算子可以写成：

```math
\boxed{
f(v)
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)
}
```

这里的 $\max$ 是逐分量取最大值，而不是对整个向量取一个标量最大值。

具体来说：

```math
(f(v))(s)
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)(s)
```

矩阵中的第 $s$ 行对应状态 $s$，因此每个状态可以独立选择使该行结果最大的动作。

例如：

- 状态 $s_1$ 可以选择动作 $a_2$；
- 状态 $s_2$ 可以选择动作 $a_1$；
- 状态 $s_3$ 可以选择动作 $a_3$。

这些逐状态动作组合起来构成一个完整策略。

一般不能写成：

```math
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)
=
\max_\pi r_\pi
+
\gamma
\left(
\max_\pi P_\pi
\right)v
```

因为奖励项和未来价值项必须作为一个整体进行比较。

正确的最大化对象是：

```math
r(s,a)
+
\gamma P_a(s,:)v
```

---

# 7. Bellman 最优算子的压缩性

需要证明：

```math
\boxed{
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

## 7.1 最大值不等式

对于任意两组实数 $\{x_a\}$ 和 $\{y_a\}$：

```math
\boxed{
\left|
\max_a x_a-\max_a y_a
\right|
\le
\max_a|x_a-y_a|
}
```

证明如下。

令：

```math
a_1
\in
\operatorname*{arg\,max}_a x_a
```

则：

```math
\max_a x_a=x_{a_1}
```

同时：

```math
\max_a y_a\ge y_{a_1}
```

所以：

```math
\max_a x_a-\max_a y_a
\le
x_{a_1}-y_{a_1}
\le
\max_a|x_a-y_a|
```

交换 $x$ 和 $y$，同样可以得到：

```math
\max_a y_a-\max_a x_a
\le
\max_a|x_a-y_a|
```

因此：

```math
\left|
\max_a x_a-\max_a y_a
\right|
\le
\max_a|x_a-y_a|
```

---

## 7.2 应用于 Bellman 最优算子

固定状态 $s$，定义：

```math
x_a
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_1(s')
```

以及：

```math
y_a
=
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v_2(s')
```

那么：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&=
\left|
\max_a x_a-\max_a y_a
\right|\\
&\le
\max_a|x_a-y_a|
\end{aligned}
```

奖励项相消，因此：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&\le
\gamma
\max_a
\left|
\sum_{s'}
P(s'\mid s,a)
\left(
v_1(s')-v_2(s')
\right)
\right|\\
&\le
\gamma
\max_a
\sum_{s'}
P(s'\mid s,a)
\left|
v_1(s')-v_2(s')
\right|
\end{aligned}
```

根据无穷范数定义：

```math
|v_1(s')-v_2(s')|
\le
\lVert v_1-v_2\rVert_\infty
```

所以：

```math
\begin{aligned}
|(f(v_1))(s)-(f(v_2))(s)|
&\le
\gamma
\max_a
\sum_{s'}
P(s'\mid s,a)
\lVert v_1-v_2\rVert_\infty\\
&=
\gamma
\lVert v_1-v_2\rVert_\infty
\end{aligned}
```

最后对所有状态取最大值：

```math
\boxed{
\lVert f(v_1)-f(v_2)\rVert_\infty
\le
\gamma
\lVert v_1-v_2\rVert_\infty
}
```

因为 $\gamma<1$，所以 Bellman 最优算子 $f$ 是一个压缩映射。

---

# 8. 压缩映射定理带来的结论

由于 $f$ 是压缩映射，Bellman 最优方程：

```math
v=f(v)
```

具有以下性质。

## 8.1 存在性

存在一个价值向量 $v^*$ 满足：

```math
v^*=f(v^*)
```

---

## 8.2 唯一性

该不动点是唯一的。

不存在两个不同的价值向量同时满足 Bellman 最优方程。

---

## 8.3 Value iteration 收敛

任取一个有限的初始向量 $v_0$，定义：

```math
v_{k+1}
=
f(v_k)
```

即：

```math
v_{k+1}
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v_k
\right)
```

则：

```math
v_k
\longrightarrow
v^*
```

---

## 8.4 收敛速度

误差满足：

```math
\boxed{
\lVert v_k-v^*\rVert_\infty
\le
\gamma^k
\lVert v_0-v^*\rVert_\infty
}
```

因此：

- $\gamma$ 较小时，理论收敛通常较快；
- $\gamma$ 越接近 $1$，理论收敛通常越慢。

也可以使用 Bellman residual 估计误差：

```math
\boxed{
\lVert v-v^*\rVert_\infty
\le
\frac{1}{1-\gamma}
\lVert f(v)-v\rVert_\infty
}
```

---

# 9. 从 $v^*$ 构造策略 $\pi^*$

已知：

```math
v^*
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v^*
\right)
```

选择一个能够取得最大值的策略：

```math
\boxed{
\pi^*
\in
\operatorname*{arg\,max}_\pi
\left(
r_\pi+\gamma P_\pi v^*
\right)
}
```

逐状态写为：

```math
\boxed{
\pi^*(s)
\in
\operatorname*{arg\,max}_a
\left[
r(s,a)
+
\gamma
\sum_{s'}
P(s'\mid s,a)v^*(s')
\right]
}
```

由于 $\pi^*$ 取得了最大值：

```math
v^*
=
r_{\pi^*}
+
\gamma P_{\pi^*}v^*
```

即：

```math
v^*
=
f_{\pi^*}(v^*)
```

这说明 $v^*$ 是固定策略算子 $f_{\pi^*}$ 的一个不动点。

而 $f_{\pi^*}$ 是压缩映射，所以其不动点唯一。该唯一不动点就是策略 $\pi^*$ 的价值函数 $v_{\pi^*}$。

因此：

```math
\boxed{
v^*=v_{\pi^*}
}
```

这一步证明了 Bellman 最优方程的数学解 $v^*$，确实可以由一个实际策略 $\pi^*$ 实现。

---

# 10. 证明 $\pi^*$ 是最优策略

只证明：

```math
v^*=v_{\pi^*}
```

还不足以说明 $\pi^*$ 比所有其他策略都好。

还需要证明：

```math
\boxed{
v^*\ge v_\pi,
\qquad
\forall\pi
}
```

这里的不等号是逐状态意义：

```math
v^*(s)\ge v_\pi(s),
\qquad
\forall s,\ \forall\pi
```

---

## 10.1 固定任意策略 $\pi$

为了避免最大化变量和已经固定的策略 $\pi$ 混淆，把最大化变量暂时写成 $\bar{\pi}$。

由 Bellman 最优方程：

```math
v^*
=
\max_{\bar{\pi}}
\left(
r_{\bar{\pi}}
+
\gamma P_{\bar{\pi}}v^*
\right)
```

最大值一定不小于其中任意一个候选策略 $\pi$，所以：

```math
v^*
\ge
r_\pi+\gamma P_\pi v^*
```

即：

```math
v^*
\ge
f_\pi(v^*)
```

---

## 10.2 固定策略算子的单调性

如果：

```math
x\ge y
```

那么：

```math
\begin{aligned}
f_\pi(x)-f_\pi(y)
&=
r_\pi+\gamma P_\pi x
-
r_\pi-\gamma P_\pi y\\
&=
\gamma P_\pi(x-y)
\end{aligned}
```

由于：

```math
x-y\ge0
```

并且 $P_\pi$ 的所有元素都非负，所以：

```math
P_\pi(x-y)\ge0
```

因此：

```math
\boxed{
x\ge y
\quad\Longrightarrow\quad
f_\pi(x)\ge f_\pi(y)
}
```

这就是固定策略 Bellman 算子的单调性。

---

## 10.3 反复应用 $f_\pi$

已经得到：

```math
v^*
\ge
f_\pi(v^*)
```

根据单调性，对两边同时作用 $f_\pi$：

```math
f_\pi(v^*)
\ge
f_\pi^2(v^*)
```

继续下去：

```math
v^*
\ge
f_\pi(v^*)
\ge
f_\pi^2(v^*)
\ge
f_\pi^3(v^*)
\ge
\cdots
```

由于 $f_\pi$ 是压缩映射，从任意初始值开始迭代都会收敛到唯一不动点 $v_\pi$：

```math
f_\pi^k(v^*)
\longrightarrow
v_\pi
```

令 $k\to\infty$，得到：

```math
\boxed{
v^*\ge v_\pi
}
```

由于一开始的 $\pi$ 是任意策略：

```math
\boxed{
v^*\ge v_\pi,
\qquad
\forall\pi
}
```

再结合：

```math
v^*=v_{\pi^*}
```

得到：

```math
\boxed{
v_{\pi^*}
=
v^*
\ge
v_\pi,
\qquad
\forall\pi
}
```

因此：

```math
\boxed{
\pi^*\text{ 是最优策略}
}
```

并且：

```math
\boxed{
v^*(s)
=
\max_\pi v_\pi(s)
}
```

注意：

- 最优价值函数 $v^*$ 是唯一的；
- 最优策略 $\pi^*$ 不一定唯一；
- 如果多个动作在某些状态并列最大，就可能存在多个最优策略。

---

# 11. Reward 的仿射变换

为了避免和动作符号 $a$ 混淆，这一节使用 $\alpha$ 表示奖励缩放系数。

假设每一步奖励统一变换为：

```math
R'_{t+1}
=
\alpha R_{t+1}
+
b
```

要保证最优策略不变，需要：

```math
\boxed{
\alpha>0
}
```

而不仅仅是 $\alpha\ne0$。

---

## 11.1 Return 的变化

原来的 Return 为：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

变换后的 Return 为：

```math
\begin{aligned}
G'_t
&=
\sum_{k=0}^{\infty}
\gamma^k
\left(
\alpha R_{t+k+1}+b
\right)\\
&=
\alpha
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
+
b
\sum_{k=0}^{\infty}
\gamma^k\\
&=
\alpha G_t
+
\frac{b}{1-\gamma}
\end{aligned}
```

因此：

```math
\boxed{
G'_t
=
\alpha G_t
+
\frac{b}{1-\gamma}
}
```

---

## 11.2 固定策略 state value 的变化

对于任意固定策略 $\pi$：

```math
\begin{aligned}
v'_\pi(s)
&=
\mathbb{E}_\pi
\left[
G'_t
\mid
S_t=s
\right]\\
&=
\mathbb{E}_\pi
\left[
\alpha G_t
+
\frac{b}{1-\gamma}
\mid
S_t=s
\right]\\
&=
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
\end{aligned}
```

所以：

```math
\boxed{
v'_\pi(s)
=
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
}
```

向量形式为：

```math
\boxed{
v'_\pi
=
\alpha v_\pi
+
\frac{b}{1-\gamma}\mathbf{1}
}
```

其中：

```math
\mathbf{1}
=
\begin{bmatrix}
1\\
1\\
\vdots\\
1
\end{bmatrix}
```

---

## 11.3 固定策略 action value 的变化

同理：

```math
\begin{aligned}
q'_\pi(s,a)
&=
\mathbb{E}_\pi
\left[
G'_t
\mid
S_t=s,\ A_t=a
\right]\\
&=
\alpha q_\pi(s,a)
+
\frac{b}{1-\gamma}
\end{aligned}
```

因此：

```math
\boxed{
q'_\pi(s,a)
=
\alpha q_\pi(s,a)
+
\frac{b}{1-\gamma}
}
```

---

## 11.4 最优 state value 的变化

变换后的最优价值函数为：

```math
v'^*(s)
=
\max_\pi v'_\pi(s)
```

代入前面的关系：

```math
v'^*(s)
=
\max_\pi
\left[
\alpha v_\pi(s)
+
\frac{b}{1-\gamma}
\right]
```

由于 $\alpha>0$，正数缩放不会改变大小关系，因此：

```math
\begin{aligned}
v'^*(s)
&=
\alpha
\max_\pi v_\pi(s)
+
\frac{b}{1-\gamma}\\
&=
\alpha v^*(s)
+
\frac{b}{1-\gamma}
\end{aligned}
```

所以：

```math
\boxed{
v'^*
=
\alpha v^*
+
\frac{b}{1-\gamma}\mathbf{1}
}
```

---

## 11.5 最优 action value 的变化

同理：

```math
\boxed{
q'^*(s,a)
=
\alpha q^*(s,a)
+
\frac{b}{1-\gamma}
}
```

---

## 11.6 为什么最优策略不变

变换前的最优动作集合为：

```math
\operatorname*{arg\,max}_a
q^*(s,a)
```

变换后的最优动作集合为：

```math
\operatorname*{arg\,max}_a
q'^*(s,a)
```

代入：

```math
\operatorname*{arg\,max}_a
\left[
\alpha q^*(s,a)
+
\frac{b}{1-\gamma}
\right]
```

其中：

- $\frac{b}{1-\gamma}$ 对所有动作都相同，不影响动作排序；
- $\alpha>0$，正数缩放不改变大小顺序。

因此：

```math
\boxed{
\operatorname*{arg\,max}_a
q'^*(s,a)
=
\operatorname*{arg\,max}_a
q^*(s,a)
}
```

所以最优策略集合不变。

如果 $\alpha<0$，大小顺序会反转：

```math
x_1>x_2
\quad\Longrightarrow\quad
\alpha x_1<\alpha x_2
```

因此不能保证最优策略不变。

---

## 11.7 适用条件

公式：

```math
\frac{b}{1-\gamma}
```

适用于无限时域折扣任务，或者终止状态之后仍被视为进入一个吸收状态并继续产生相同形式的奖励。

如果是有限时域任务，常数项会变成：

```math
b
\sum_{k=0}^{H-1}
\gamma^k
=
b
\frac{1-\gamma^H}{1-\gamma}
```

如果不同策略会产生不同的 episode 长度，并且终止后不再获得奖励，那么给每一步统一增加常数 $b$ 可能改变智能体对 episode 长度的偏好，此时最优策略不一定保持不变。

---

# 12. Reward 与折扣因子 $\gamma$ 的真正含义

## 12.1 Reward 决定“什么是好结果”

Reward 定义智能体优化的目标。

例如：

- 到达目标奖励为 $+1$；
- 撞墙奖励为 $-1$；
- 每移动一步奖励为 $-0.01$；
- 收集物品奖励为正；
- 进入危险区域奖励为负。

因此：

```math
\text{Reward}
\quad\Longrightarrow\quad
\text{智能体应该偏好什么结果}
```

Reward 并不是对状态价值的直接赋值。

状态价值是未来 Return 的期望：

```math
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
```

Reward 通过 Return 间接决定 state value 和 action value。

---

## 12.2 折扣因子决定“未来奖励有多重要”

Return 中，第 $k$ 步后的奖励权重是：

```math
\gamma^k
```

当 $\gamma$ 较小时：

- 更重视近期奖励；
- 较远奖励迅速贬值；
- 有效规划范围较短；
- Bellman 迭代通常更快收敛。

当 $\gamma$ 接近 $1$ 时：

- 更重视长期奖励；
- 较远奖励仍然有较大影响；
- 有效规划范围更长；
- Bellman 迭代理论上更慢。

一个常用的粗略有效时间尺度是：

```math
\frac{1}{1-\gamma}
```

例如：

```math
\gamma=0.9
\quad\Longrightarrow\quad
\frac{1}{1-\gamma}=10
```

```math
\gamma=0.99
\quad\Longrightarrow\quad
\frac{1}{1-\gamma}=100
```

这不是严格的截止步数，而是一个直观的长期影响范围。

---

# 13. 九宫格中为什么零步进奖励也可能得到短路径

假设：

- 普通白色格子的奖励为 $0$；
- 到达目标获得奖励 $R_g>0$；
- 途中没有其他奖励；
- 从当前状态经过 $d$ 步到达目标；
- $0<\gamma<1$。

如果目标奖励在第 $d$ 步获得，那么当前 Return 约为：

```math
G_t
=
\gamma^{d-1}R_g
```

假设两条路径长度满足：

```math
d_1<d_2
```

由于：

```math
0<\gamma<1
```

所以：

```math
\gamma^{d_1-1}
>
\gamma^{d_2-1}
```

因此：

```math
\gamma^{d_1-1}R_g
>
\gamma^{d_2-1}R_g
```

较短路径的价值更高。

此时，并不是白色格子的零奖励在惩罚绕路，而是：

```math
\boxed{
\gamma<1
\text{ 使较晚得到的目标奖励发生折扣}
}
```

---

## 13.1 当 $\gamma=1$ 时

如果：

- 所有普通格子奖励为 $0$；
- 所有路径最终到达同一个奖励为 $R_g$ 的目标；
- 不考虑失败概率和其他奖励；
- $\gamma=1$。

那么无论经过多少步：

```math
G_t=R_g
```

因此，长路径和短路径具有相同 Return。

这时目标函数本身并不严格偏好最短路径。

算法最后恰好找到短路径，可能来自：

- 初始化方式；
- 探索过程；
- 动作的平局处理；
- 更新顺序；
- 环境的具体实现。

但这不代表短路径在价值上严格优于长路径。

---

## 13.2 每步负奖励的作用

另一种鼓励短路径的方法，是让每走一步产生负奖励。

例如：

```math
R_{t+1}=-c,
\qquad
c>0
```

假设经过 $d$ 步到达奖励为 $R_g$ 的目标，并且 $\gamma=1$，那么 Return 可能为：

```math
G_t
=
R_g-c(d-1)
```

路径越长，累计负奖励越多，所以短路径具有更高价值。

---

## 13.3 每步惩罚与折扣的区别

两者都可能鼓励短路径，但含义不同：

```math
\boxed{
\begin{aligned}
\text{每步负奖励}
&:
\text{延迟或移动本身具有实际成本}\\
\gamma<1
&:
\text{未来奖励相对于近期奖励发生贬值}
\end{aligned}
}
```

它们并不完全等价。

当环境中存在以下因素时，最优策略不一定是几何距离最短的路径：

- 路径中的额外奖励；
- 危险区域；
- 随机状态转移；
- 多个不同奖励的终点；
- 不同路径具有不同成功概率；
- 某些动作消耗不同资源。

智能体真正最大化的是：

```math
\mathbb{E}_\pi
\left[
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
\right]
```

而不是单纯最小化路径长度。

---

# 14. Reward、$\gamma$、环境与价值函数之间的关系

可以把各部分的作用总结为：

```math
\boxed{
\begin{aligned}
R
&:
\text{定义什么结果值得追求}\\
\gamma
&:
\text{定义未来奖励相对于近期奖励的重要程度}\\
P
&:
\text{定义环境在动作后如何变化}\\
\pi
&:
\text{定义智能体如何选择动作}\\
v_\pi,\ q_\pi
&:
\text{表示上述因素共同作用后的期望折扣回报}
\end{aligned}
}
```

因此，reward 和 $\gamma$ 都会影响 state value，但它们不是直接手工设置 state value。

它们首先定义 Return：

```math
G_t
=
\sum_{k=0}^{\infty}
\gamma^kR_{t+k+1}
```

然后 state value 是 Return 的条件期望：

```math
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
```

# 15. 整体逻辑总结

固定策略 Bellman 算子：

```math
f_\pi(v)
=
r_\pi+\gamma P_\pi v
```

固定策略价值函数满足：

```math
v_\pi
=
f_\pi(v_\pi)
```

由于 $f_\pi$ 是压缩映射，所以：

```math
v_\pi
```

是唯一固定点，并且固定策略价值迭代收敛到 $v_\pi$。

Bellman 最优算子：

```math
f(v)
=
\max_\pi
\left(
r_\pi+\gamma P_\pi v
\right)
```

Bellman 最优方程：

```math
v^*
=
f(v^*)
```

由于 $f$ 是压缩映射，所以：

1. $v^*$ 存在；
2. $v^*$ 唯一；
3. Value iteration 从任意初始值收敛到 $v^*$。

Value iteration 为：

```math
v_{k+1}
=
f(v_k)
```

根据 $v^*$ 构造贪心策略：

```math
\pi^*
\in
\operatorname*{arg\,max}_\pi
\left(
r_\pi+\gamma P_\pi v^*
\right)
```

于是：

```math
v^*
=
r_{\pi^*}
+
\gamma P_{\pi^*}v^*
```

固定策略算子 $f_{\pi^*}$ 的不动点唯一，所以：

```math
v^*
=
v_{\pi^*}
```

对于任意策略 $\pi$：

```math
v^*
\ge
v_\pi
```

因此：

```math
\boxed{
v_{\pi^*}
=
v^*
=
\max_\pi v_\pi
}
```

并且：

```math
\boxed{
\pi^*\text{ 是最优策略}
}
```

整套逻辑可以概括为：

```math
\boxed{
\begin{aligned}
\text{Bellman 算子具有压缩性}
&\Longrightarrow
\text{存在唯一不动点}\\
&\Longrightarrow
\text{价值迭代收敛}\\
&\Longrightarrow
\text{可以由 }v^*\text{ 构造贪心策略 }\pi^*\\
&\Longrightarrow
v_{\pi^*}=v^*\ge v_\pi,\ \forall\pi
\end{aligned}
}
```
