# 贝尔曼公式的理解
# 日期：2026.7.19
# 贝尔曼方程 Bellman Equation

贝尔曼方程的核心思想是：

> 将长期回报拆分为“当前一步的奖励”和“下一状态价值的折扣”。

本节只讨论固定策略 $\pi$ 下的 value function，不涉及最优贝尔曼方程。

---

## 1. 回报的递推形式

从时刻 $t$ 开始，折扣回报定义为：

$$
G_t
=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2 R_{t+3}
+
\cdots
$$

也可以写成：

$$
G_t
=
\sum_{k=0}^{\infty}
\gamma^k R_{t+k+1}
$$

其中：

- $R_{t+1}$ 表示执行当前动作后获得的即时奖励；
- $\gamma\in[0,1)$ 表示折扣因子；
- 越遥远的未来奖励，其权重越低。

将第一项单独提取出来：

$$
\begin{aligned}
G_t
&=
R_{t+1}
+
\gamma R_{t+2}
+
\gamma^2 R_{t+3}
+
\cdots
\\
&=
R_{t+1}
+
\gamma
\left(
R_{t+2}
+
\gamma R_{t+3}
+
\gamma^2 R_{t+4}
+
\cdots
\right)
\end{aligned}
$$

括号中的部分正是 $G_{t+1}$，因此：

$$
\boxed{
G_t
=
R_{t+1}
+
\gamma G_{t+1}
}
$$

这就是贝尔曼方程能够建立递归关系的基础。

---

## 2. State Value

在策略 $\pi$ 下，状态 $s$ 的 state value 定义为：

$$
\boxed{
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
}
$$

它表示：

> 当智能体处于状态 $s$，并且之后始终按照策略 $\pi$ 选择动作时，能够获得的期望折扣回报。

将回报的递推关系

$$
G_t
=
R_{t+1}
+
\gamma G_{t+1}
$$

代入 state value 的定义：

$$
v_\pi(s)
=
\mathbb{E}_\pi
\left[
R_{t+1}
+
\gamma G_{t+1}
\mid
S_t=s
\right]
$$

从下一状态开始的期望回报，就是下一状态的 state value，因此：

$$
\boxed{
v_\pi(s)
=
\mathbb{E}_\pi
\left[
R_{t+1}
+
\gamma v_\pi(S_{t+1})
\mid
S_t=s
\right]
}
$$

这就是 state value 的 Bellman expectation equation。

---

## 3. 将奖励和状态转移分开表示

为了避免将下一状态 $s'$ 和奖励 $r$ 写在同一个联合概率中，分别定义状态转移概率和期望即时奖励。

### 3.1 状态转移概率

$$
\boxed{
p(s'\mid s,a)
=
\Pr
\left(
S_{t+1}=s'
\mid
S_t=s,A_t=a
\right)
}
$$

它表示：

> 在状态 $s$ 执行动作 $a$ 后，转移到状态 $s'$ 的概率。

---

### 3.2 期望即时奖励

定义：

$$
\boxed{
r(s,a,s')
=
\mathbb{E}
\left[
R_{t+1}
\mid
S_t=s,A_t=a,S_{t+1}=s'
\right]
}
$$

它表示：

> 在状态 $s$ 执行动作 $a$，并且转移到状态 $s'$ 时，期望获得的即时奖励。

---

## 4. State Value 的贝尔曼期望方程

在状态 $s$ 下：

1. 智能体根据策略 $\pi(a\mid s)$ 选择动作 $a$；
2. 环境根据 $p(s'\mid s,a)$ 转移到下一状态 $s'$；
3. 智能体获得期望奖励 $r(s,a,s')$；
4. 下一状态具有价值 $v_\pi(s')$。

因此：

$$
\boxed{
v_\pi(s)
=
\sum_a
\pi(a\mid s)
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma v_\pi(s')
\right]
}
$$

这个方程可以理解为：

$$
\text{当前状态的价值}
=
\text{当前奖励的期望}
+
\text{下一状态价值的折扣期望}
$$

注意，当前状态下的动作并没有固定，因此需要按照策略 $\pi(a\mid s)$ 对所有可能动作求期望。

---

## 5. 固定策略下的奖励和转移概率

当策略 $\pi$ 固定以后，可以将策略和环境的状态转移合并。

### 5.1 策略 $\pi$ 下的期望即时奖励

定义：

$$
\boxed{
r_\pi(s)
=
\sum_a
\pi(a\mid s)
\sum_{s'}
p(s'\mid s,a)
r(s,a,s')
}
$$

它表示：

> 从状态 $s$ 出发，按照策略 $\pi$ 选择动作后，一步所能获得的期望奖励。

---

### 5.2 策略 $\pi$ 下的状态转移概率

定义：

$$
\boxed{
P_\pi(s,s')
=
\sum_a
\pi(a\mid s)
p(s'\mid s,a)
}
$$

它表示：

> 从状态 $s$ 出发，按照策略 $\pi$ 选择动作后，转移到状态 $s'$ 的概率。

因此，state value 的贝尔曼期望方程可以写成更加简洁的形式：

$$
\boxed{
v_\pi(s)
=
r_\pi(s)
+
\gamma
\sum_{s'}
P_\pi(s,s')v_\pi(s')
}
$$

固定策略以后，原来的 MDP 可以看作一个 Markov Reward Process。

---

## 6. Matrix-Vector Form

假设有限状态空间为：

$$
\mathcal{S}
=
\{s_1,s_2,\ldots,s_n\}
$$

将所有状态的 state value 写成列向量：

$$
\mathbf{v}_\pi
=
\begin{bmatrix}
v_\pi(s_1)
\\
v_\pi(s_2)
\\
\vdots
\\
v_\pi(s_n)
\end{bmatrix}
$$

将所有状态的期望即时奖励写成列向量：

$$
\mathbf{r}_\pi
=
\begin{bmatrix}
r_\pi(s_1)
\\
r_\pi(s_2)
\\
\vdots
\\
r_\pi(s_n)
\end{bmatrix}
$$

策略 $\pi$ 对应的状态转移矩阵为：

$$
\mathbf{P}_\pi
=
\begin{bmatrix}
P_\pi(s_1,s_1)
&
P_\pi(s_1,s_2)
&
\cdots
&
P_\pi(s_1,s_n)
\\
P_\pi(s_2,s_1)
&
P_\pi(s_2,s_2)
&
\cdots
&
P_\pi(s_2,s_n)
\\
\vdots
&
\vdots
&
\ddots
&
\vdots
\\
P_\pi(s_n,s_1)
&
P_\pi(s_n,s_2)
&
\cdots
&
P_\pi(s_n,s_n)
\end{bmatrix}
$$

其中，第 $i$ 行第 $j$ 列表示：

$$
[\mathbf{P}_\pi]_{ij}
=
P_\pi(s_i,s_j)
$$

也就是从状态 $s_i$ 转移到状态 $s_j$ 的概率。

所有状态的贝尔曼方程可以统一写成：

$$
\boxed{
\mathbf{v}_\pi
=
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_\pi
}
$$

移项得到：

$$
\mathbf{v}_\pi
-
\gamma
\mathbf{P}_\pi
\mathbf{v}_\pi
=
\mathbf{r}_\pi
$$

提取 $\mathbf{v}_\pi$：

$$
\left(
\mathbf{I}
-
\gamma\mathbf{P}_\pi
\right)
\mathbf{v}_\pi
=
\mathbf{r}_\pi
$$

因此：

$$
\boxed{
\mathbf{v}_\pi
=
\left(
\mathbf{I}
-
\gamma\mathbf{P}_\pi
\right)^{-1}
\mathbf{r}_\pi
}
$$

这说明：

> 在环境模型和策略已知的情况下，所有状态的 state value 可以通过求解一个线性方程组得到。

---

## 7. 迭代求解 State Value

当状态数量较多时，直接计算矩阵逆的代价较高。

因此，可以采用迭代方法：

$$
\boxed{
\mathbf{v}_{k+1}
=
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_k
}
$$

其中：

- $\mathbf{v}_0$ 是任意初始化的 value vector；
- $\mathbf{v}_k$ 是第 $k$ 次迭代得到的估计；
- 随着迭代次数增加，$\mathbf{v}_k$ 会逐渐接近真实的 $\mathbf{v}_\pi$。

对于单个状态，迭代更新为：

$$
\boxed{
v_{k+1}(s)
=
\sum_a
\pi(a\mid s)
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma v_k(s')
\right]
}
$$

常用的停止条件是：

$$
\left\|
\mathbf{v}_{k+1}
-
\mathbf{v}_k
\right\|_\infty
<
\varepsilon
$$

其中无穷范数定义为：

$$
\|\mathbf{x}\|_\infty
=
\max_i |x_i|
$$

---

## 8. 迭代法的简单收敛证明

真实的 state value 满足：

$$
\mathbf{v}_\pi
=
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_\pi
$$

迭代值满足：

$$
\mathbf{v}_{k+1}
=
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_k
$$

将两个式子做差：

$$
\begin{aligned}
\mathbf{v}_{k+1}
-
\mathbf{v}_\pi
&=
\left(
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_k
\right)
-
\left(
\mathbf{r}_\pi
+
\gamma
\mathbf{P}_\pi
\mathbf{v}_\pi
\right)
\\
&=
\gamma
\mathbf{P}_\pi
\left(
\mathbf{v}_k
-
\mathbf{v}_\pi
\right)
\end{aligned}
$$

继续递推：

$$
\mathbf{v}_k
-
\mathbf{v}_\pi
=
\left(
\gamma\mathbf{P}_\pi
\right)^k
\left(
\mathbf{v}_0
-
\mathbf{v}_\pi
\right)
$$

由于 $\mathbf{P}_\pi$ 是状态转移矩阵，每一行的元素都非负，并且每一行元素之和为 $1$，因此对于任意向量 $\mathbf{x}$：

$$
\left\|
\mathbf{P}_\pi\mathbf{x}
\right\|_\infty
\leq
\|\mathbf{x}\|_\infty
$$

于是：

$$
\begin{aligned}
\left\|
\mathbf{v}_k
-
\mathbf{v}_\pi
\right\|_\infty
&=
\left\|
\left(
\gamma\mathbf{P}_\pi
\right)^k
\left(
\mathbf{v}_0
-
\mathbf{v}_\pi
\right)
\right\|_\infty
\\
&\leq
\gamma^k
\left\|
\mathbf{v}_0
-
\mathbf{v}_\pi
\right\|_\infty
\end{aligned}
$$

因为：

$$
0\leq\gamma<1
$$

所以：

$$
\lim_{k\to\infty}\gamma^k
=
0
$$

从而：

$$
\boxed{
\lim_{k\to\infty}
\left\|
\mathbf{v}_k
-
\mathbf{v}_\pi
\right\|_\infty
=
0
}
$$

因此：

$$
\boxed{
\lim_{k\to\infty}
\mathbf{v}_k
=
\mathbf{v}_\pi
}
$$

也就是说，无论初始值 $\mathbf{v}_0$ 如何选择，只要 $\gamma<1$，迭代结果最终都会收敛到真实的 state value。

## 9. Action Value

在策略 $\pi$ 下，状态—动作对 $(s,a)$ 的 action value 定义为：

$$
\boxed{
q_\pi(s,a)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s,A_t=a
\right]
}
$$

它表示：

> 在状态 $s$ 下先执行动作 $a$，之后继续按照策略 $\pi$ 选择动作时，能够获得的期望折扣回报。

将回报的递推关系代入：

$$
q_\pi(s,a)
=
\mathbb{E}_\pi
\left[
R_{t+1}
+
\gamma G_{t+1}
\mid
S_t=s,A_t=a
\right]
$$

由于当前动作 $a$ 已经固定，所以只需要对下一状态求期望：

$$
\boxed{
q_\pi(s,a)
=
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma v_\pi(s')
\right]
}
$$

与 state value 相比，action value 固定了当前动作，因此不需要再对当前动作按照 $\pi(a\mid s)$ 求期望。

---

## 10. State Value 与 Action Value 的关系

在状态 $s$ 下，智能体按照策略 $\pi$ 选择动作，因此 state value 是所有 action value 的加权平均：

$$
\boxed{
v_\pi(s)
=
\sum_a
\pi(a\mid s)
q_\pi(s,a)
}
$$

另一方面，action value 可以通过下一状态的 state value 表示：

$$
\boxed{
q_\pi(s,a)
=
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma v_\pi(s')
\right]
}
$$

又因为：

$$
v_\pi(s')
=
\sum_{a'}
\pi(a'\mid s')
q_\pi(s',a')
$$

将其代入 action value 的表达式：

$$
q_\pi(s,a)
=
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma
\sum_{a'}
\pi(a'\mid s')
q_\pi(s',a')
\right]
$$

因此，action value 的 Bellman expectation equation 为：

$$
\boxed{
q_\pi(s,a)
=
\sum_{s'}
p(s'\mid s,a)
\left[
r(s,a,s')
+
\gamma
\sum_{a'}
\pi(a'\mid s')
q_\pi(s',a')
\right]
}
$$

它表达的是：

$$
\text{当前 action value}
=
\text{期望即时奖励}
+
\text{下一步 action value 的折扣期望}
$$

---

## 11. State Value 与 Action Value 的区别

### State Value

$$
v_\pi(s)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s
\right]
$$

只给定当前状态，没有固定当前动作。

因此，需要按照策略 $\pi(a\mid s)$ 对当前动作求期望。

---

### Action Value

$$
q_\pi(s,a)
=
\mathbb{E}_\pi
\left[
G_t
\mid
S_t=s,A_t=a
\right]
$$

不仅给定当前状态，还固定了当前动作。

因此，只需要对下一状态和之后的动作求期望。

---
